# Supplementary

Supplementary files cited in the paper. All tables were produced by `Morphological_Analysis/Maize_analysis_v3_2026-11-27.R` on the same 344 cobs unless noted.

| File | Cited in the paper as | Contents |
|---|---|---|
| `Supplementary_Morphology_Stats.xlsx` | Supplementary Morphology Stats | Descriptive statistics; MANOVA and univariate tests across all sites |
| `Supplementary_PCA.xlsx` | Supplementary PCA | Variance explained and loadings of the PCA (Figure 3) |
| `Supplementary_Period_MANOVA.xlsx` | Supplementary Period MANOVA | MANOVA across periods |
| `Supplementary_Period_Comparisons.xlsx` | Supplementary Period Comparisons | Welch ANOVA per trait (η², BH-adjusted p) and Games–Howell pairwise tests with 95% CIs and Hedges' g |
| `Supplementary_CDA.xlsx` | Supplementary CDA | Canonical dimensions, structure loadings and n per site (Figure 5) |
| `Supplementary_MH_Traits_with_AllSites.xlsx` | Supplementary MH Traits with All Sites | MANOVA, univariate tests and Tukey HSD among Middle Horizon sites (297 cobs) |
| `Supplementary_LIP_Traits_with_AllSites.xlsx` | Supplementary LIP Traits with All Sites | MANOVA, univariate tests and Tukey HSD between the two LIP sites (15 cobs) |
| `Supplementary_ChenChen_vs_Omo.xlsx` | Supplementary Chen Chen vs Omo | Wilcoxon rank-sum test on PC1 (Chen Chen M1 + M43 vs Omo M12) with effect size r |
| `Supplementary_3D_Model_Key.xlsx` | Supplementary 3D Maize Model Key | The 70 second-phase cobs with 3D models: original code, specimen ID, site, period and measurements; PCA scores of the 36 cobs in the geometric morphometric analysis |
| `Supplementary_Batch2_Cob_Data_and_Conversion_Check.xlsx` | Supplementary Conversion Check | Raw pixel measurements of the second-phase cobs, the pixel-to-mm conversion, and its check against caliper measurements |
| `Supplementary_Plane_outline.png` | Supplementary Plane_outline.png | Orientation of the outline plane for the geometric morphometric analysis |
| `Revision_Supplementary_AMS_full.csv` | Supplementary AMS table | All 20 AMS dates with 68.3% and 95.4% calibrated ranges (SHCal20) |

Video of the outline-plane procedure: https://doi.org/10.5281/zenodo.23500772
